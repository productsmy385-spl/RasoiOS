# Accessibility (WCAG 2.1 AA) Compliance

- Semantic HTML tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- Minimum contrast ratio 4.5:1 for body text against dark `#1A1715` background.
- Visible focus rings (`focus:ring-2 focus:ring-[#D97706]`) on all interactive buttons and inputs.
- Screen-reader aria attributes (`aria-label`, `aria-live="polite"` for kitchen order updates).
