# Visual Design Identity & Aesthetic System

## 1. Design Vision & Aesthetic Direction
- **Brand Personality**: Premium traditional restaurant meets modern high-performance SaaS.
- **Visual Feel**: Polished, warm culinary imagery, dark premium surfaces, rich amber glow accents, emerald live operational states, selective glassmorphism, restrained gradients, purposeful micro-animations.
- **Prohibited Styles**: Neon colors, generic admin templates, excessive blur, noisy backgrounds, dead buttons, fake placeholder screens.

## 2. Master Color Palette

| Token Role | Hex Code | Purpose |
|---|:---:|---|
| **Primary** | `#D97706` | Amber accent, primary actions, highlights, brand badges |
| **Primary Hover** | `#B45309` | Hover state for buttons and interactive controls |
| **Secondary Canvas** | `#FBF9F5` | Warm light surface background for public menus |
| **Neutral Dark Surface**| `#1A1715` | Dark premium background for manager/kitchen portal |
| **Neutral Card Surface**| `#24201D` | Glassmorphism cards and table containers |
| **Neutral Border** | `#38322E` | Subtle dividers and subtle card borders |
| **Tertiary / Success** | `#10B981` | Emerald live operational indicators, ready state, success |
| **Warning** | `#F59E0B` | Pending status, active preparation warnings |
| **Error / Destructive** | `#EF4444` | Cancelled status, payment failure, deletion alerts |

## 3. Typography Architecture
- **Display Font**: *Playfair Display* (Serif accent for headings, restaurant branding, category titles).
- **UI / Body Font**: *Plus Jakarta Sans* (Sans-serif for tables, POS totals, inputs, status badges, buttons).
